怎麼說，孩子會聽 vs. 如何聽，孩子願意說

How to Talk So Kids Will Listen & Listen So Kids Will Talk

安戴爾・法伯、依蓮・馬茲麗許（Adele Faber & Elaine Mazlish）｜1980

孩子不聽話，你以為是他欠管教？很多時候是你的第一句話就否定了他的感受——感覺不被接住的人，不管幾歲，都不會想合作。

30 秒帶走

  • 先接住感受，行為才有得談；否定感受只會讓孩子更用力證明自己真的很難過。
  • 要合作，就描述問題、給資訊、說自己的感受，別用責備、威脅和說教。
  • 懲罰與空泛稱讚都有副作用；改用一起解決問題和描述式讚美，孩子才長出自己的判斷。

作者與時代背景

安戴爾・法伯和依蓮・馬茲麗許原本是兩位住在紐約的媽媽，各有三個孩子。六〇年代末，她們參加了兒童心理學家海姆・吉諾特主持的家長團體。吉諾特是《父母怎樣跟孩子說話》的作者，他的核心想法在當時很新：孩子的感受需要被承認，大人可以限制行為，但不該否定感受。

兩人一上就是好多年，把學到的方法帶回家用在自己孩子身上，記錄哪些有效、哪些踢到鐵板，後來自己也開始帶家長工作坊。這本書 1980 年出版，內容就是她們工作坊的教材：每一章一個主題，有原則、有對照的漫畫、有練習題，還有參加過課程的家長回報的真實故事。

它不是學術著作，兩位作者也從不假裝是。但四十多年過去，它仍是親子溝通類書裡最常被推薦的一本，原因很單純：書裡的句子拿起來就能用。而且讀過的人常會發現，這些方法拿去跟伴侶、同事、年邁的父母說話，一樣管用。

這本書回答什麼問題

「為什麼我好好講他不聽，一定要等到我吼才動？」「為什麼孩子什麼都不跟我說？」

作者的回答是：問題多半不在孩子的個性，也不在你不夠愛他，而在我們從小聽慣、於是脫口而出的那些話——否定、說教、追問、威脅、比較。這些話的共同點是讓對方覺得「我的感覺不算數」或「我這個人有問題」。一個人處在這種狀態，剩下的力氣都拿去防衛和反擊，自然沒有餘裕合作。

兩位作者在書裡很誠實：她們說自己在有孩子之前都是很棒的媽媽，很清楚別人家的問題出在哪；直到自己有了三個小孩。這本書是寫給真實生活裡會累、會煩、會失控的大人的。

核心概念深講

一、先接住感受：感覺對了，行為才會對

全書的地基是一個簡單的連結：孩子的感受和行為直接相關。感覺好的時候表現好；而要讓他感覺好，第一步是接受他的感受。

可是大人最常做的剛好相反。孩子說「我好累」，我們說「你剛睡過午覺，怎麼會累」；孩子說「我討厭妹妹」，我們說「不可以這樣講」；孩子哭著說金魚死了，我們說「別哭，再買一隻就好」。每一句都是好意，但孩子聽到的是：你的感覺是錯的。

作者請讀者做一個想像練習：假設你今天在公司被主管當眾罵了一頓，回家跟朋友訴苦。朋友如果回你「你也有不對吧」（責怪）、「人生就是這樣」（講道理）、「你應該去跟他道歉」（給建議）、「他到底說了什麼？你那時候在幹嘛？」（追問）、「你主管也很辛苦」（替對方說話），你是什麼感覺？多數人會更生氣，或者乾脆閉嘴。反而是一句「聽起來真的很難堪」，會讓人鬆下來，接著自己想到下一步。

所以她們提出四個接住感受的方法：

  1. 全神貫注地聽：放下手機、轉過身來。有時候只是這樣就夠了。
  2. 用簡單的聲音回應：「喔」「嗯」「這樣啊」。不評論、不追問，孩子反而會繼續說下去，常常說著說著自己想出辦法。
  3. 說出感受的名字：「聽起來你很失望。」很多人擔心說出來會讓孩子更難過，作者的經驗相反——聽到有人講中自己的心情，孩子是被安慰到的。
  4. 用幻想滿足願望：孩子吵著要吃家裡剛好沒有的那種麥片，你解釋「家裡沒有」只會讓他吵更兇；換成「真希望我現在能變一盒給你，變一大箱！」他得不到麥片，但得到了「你懂我有多想要」。

限制：接受感受不等於接受行為。「你很氣弟弟，我看得出來。用說的告訴他，不能用打的。」所有感受都可以被接納，某些行為必須被限制，這是從吉諾特一路傳下來的原則。

常見誤用：把「我知道你很生氣」當成一句制式台詞，語氣敷衍地念出來。孩子對假的同理心非常敏感，作者說寧可只是安靜地陪著，也不要用錯的語氣說對的話。

二、鼓勵合作：五種不用吼的說法

第二章先列出大人為了讓孩子動起來常用的招數：責備、謾罵、威脅、命令、說教、警告、扮可憐、比較、挖苦、預言（「你再這樣以後沒人要跟你玩」）。然後請你站在孩子的位置聽一遍。結論很直接：這些話讓人想反抗、想躲、或者覺得自己很糟，就是不會讓人想合作。

替代方案有五個，拿「濕毛巾丟在床上」當例子：

  1. 描述你看到的：「床上有一條濕毛巾。」不說「你怎麼又」。描述問題讓孩子把注意力放在問題上，而不是忙著為自己辯護。
  2. 提供資訊：「濕毛巾會把被子弄濕。」給資訊等於相信他知道之後會自己處理。
  3. 用一個詞提醒：「毛巾。」孩子最討厭長篇大論，愈短愈有效。
  4. 說出你的感受：「我不喜歡睡在濕濕的床上。」說「我」，不說「你」，不攻擊人格。
  5. 寫張紙條：在毛巾架上貼一張「請把我掛回來，謝謝。——你的毛巾」。有趣、不帶火氣，連還不太識字的孩子都會拿著紙條來問寫了什麼。

實用價值：五招的共同精神是「對事不對人」，把「你這個人有問題」換成「這裡有一個需要解決的問題」。作者也提醒，沒有哪一招對每個孩子、每一次都有效，重點是你手上有不只一種選擇，不必每次都落回吼叫。

三、代替懲罰：讓孩子面對後果，而不是面對你

作者對懲罰的立場來自吉諾特：懲罰會讓孩子分心。被罰的孩子不會靜下來想「我做錯了什麼、要怎麼彌補」，他忙著恨你、想著怎麼報復、或者下次怎麼不被抓到。懲罰剝奪了孩子面對自己行為的那段內在過程。

她們提出的替代做法包括：強烈表達不贊同但不攻擊人格（「我很生氣，我的工具被留在外面淋雨生鏽了」）、說明你的期待、告訴孩子怎麼彌補、給他選擇、以及在必要時採取行動（工具箱鎖起來）。最後這一項和懲罰的差別在於，它是行為的自然結果，不是大人另外加上去的痛苦。

對於反覆發生的問題，她們教了一套完整的問題解決五步驟：

  1. 先談孩子的感受和需要。
  2. 再談你的感受和需要。
  3. 一起腦力激盪，找雙方都能接受的辦法。
  4. 把所有點子寫下來——不評價，再離譜的都先寫。
  5. 一起挑出喜歡的、劃掉不行的，決定怎麼執行。

第四步是關鍵。孩子看到自己提的點子被認真寫在紙上，會從「被管的人」變成「一起想辦法的人」，對最後的方案也更願意負責。

限制：這套方法花時間，而且不能在雙方都還在氣頭上的時候做。作者也承認有些方案執行幾天就失效，那就回到桌前再談一次，這本身就是在教孩子：問題是可以重新協商的。

四、自主與讚美：別替他過人生，也別亂貼標籤

後半本處理兩件容易被忽略的事。

鼓勵自主。父母的終極任務是讓孩子有一天不需要我們，但日常裡我們不斷替他做、替他想、替他回答。作者的建議是：讓孩子做選擇（「你要穿紅色還是藍色那件」）、尊重他的掙扎（「拉鍊有時候很難拉，從底下對齊可能有幫助」，而不是直接搶過來拉好）、別問太多問題、別急著給答案（「你覺得呢？」）、鼓勵他向家裡以外的資源求助、還有不要澆熄他的希望。

描述式讚美。「你好棒」「你真聰明」這種評價式的稱讚有副作用：孩子可能懷疑（「我明明沒那麼好」）、可能焦慮（「下次做不到怎麼辦」）、也可能開始依賴外界的評價。作者的做法分兩步：大人描述自己看到的和感受到的——「我看到書都放回架上、積木收進箱子、地板清空了，走進這個房間真舒服」——孩子聽完，會自己在心裡下結論：「我會整理。」這個結論是他自己得出的，別人拿不走。也可以再加一個詞總結：「這就叫有條理。」

最後一章談角色。孩子被說「固執」「懶散」「愛哭」久了，就會照著劇本演。作者建議父母主動找機會讓孩子看到自己的另一面，讓他無意間聽到你對別人說他的好話，在他又落回老樣子時說出你的感受和期待，而不是「你看你又來了」。

整本書的邏輯骨架

全書可以看成一條由內而外的路徑：感受被接住（孩子不必防衛）→ 用描述代替指責（孩子願意合作）→ 用解決問題代替懲罰（孩子學會負責）→ 放手讓他選擇與嘗試（孩子長出能力）→ 用描述代替評價（孩子建立自己對自己的看法）→ 撕掉標籤（孩子有空間變成不一樣的人）。

每一步底下是同一個信念：把孩子當成一個有感受、有判斷力的人來尊重，他就比較可能成為那樣的人。

實作指南：明天就能開始

職場版（沒錯，對大人也有用）：

  1. 同事抱怨時，先忍住給建議。說一句「聽起來很挫折」，然後停住，看他接下來說什麼。
  2. 要求別人改進時用描述：「這份報告第三頁的數字和附表對不起來」，不說「你怎麼這麼粗心」。
  3. 稱讚部屬時說具體看到的：「你把客戶的三個疑慮都先列出來回答了，他整場沒有再追問」，比「做得好」有力。
  4. 團隊反覆卡關的事，用五步驟開一次會：先各自講需要，再把點子全寫在白板上不評價，最後才挑。

生活版（以孩子不肯關平板為例）：

  1. 先接感受：「正看到精彩的地方要停下來，真的很難。」
  2. 給資訊加選擇：「晚餐好了。你要現在關，還是這一段看完再關？」
  3. 一個詞提醒：「平板。」
  4. 如果每天都上演，找個平靜的時間一起做問題解決，把雙方的點子寫下來。
  5. 他準時關掉的那一次，描述給他聽：「時間到你就自己關了，我都還沒開口。」

常見誤讀

  1. 「這是放任，不能處罰小孩就管不動」——書裡的大人會表達憤怒、會設限、會採取行動。差別是不用羞辱和額外的痛苦當工具。
  2. 「同理就是孩子說什麼都答應」——接受的是感受，不是要求。想吃麥片的孩子最後還是沒吃到麥片。
  3. 「背好句型就能搞定孩子」——作者反覆強調這是態度，不是話術。語氣不對，同一句話就變成操弄；她們也說自己常常失敗，隔天再試。

延伸對照

  • 《非暴力溝通》（盧森堡）：觀察、感受、需要、請求四步驟，和這本書的「描述、說感受、給資訊」幾乎是同一套語言的成人版。盧森堡談原理，這本給你滿滿的對照例句。
  • 《被討厭的勇氣》（岸見一郎、古賀史健）：阿德勒主張不賞不罰、用「謝謝」「幫了我大忙」這類鼓勵代替評價式的稱讚，和本書的描述式讚美方向一致；阿德勒講哲學基礎，這本講每天的實際對話。
  • 《心態致勝》（杜維克）：杜維克的研究說明為什麼稱讚「聰明」會讓孩子怕失敗，替這本書早了幾十年的直覺補上了實驗證據。
  • 《我好，你也好》（哈里斯）：這批稍後會讀到。用它的語言來說，責備和說教是「父母」自我狀態在講話，而本書教的是用「成人」自我狀態回應孩子。

金句

討論題（回訊息聊聊）

  1. 回想小時候大人最常對你說的一句話——它屬於書裡列的哪一種（否定、說教、威脅、比較）？你現在會不會也對別人說同一句？
  2. 這週找一個人（不一定是孩子），在他抱怨時只做一件事：說出他的感受然後停住。結果和你平常給建議時有什麼不同？
