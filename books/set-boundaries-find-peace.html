設限，才有好關係

Set Boundaries, Find Peace

內卓・格洛弗・塔瓦布（Nedra Glover Tawwab）｜2021

你以為自己累是因為事情太多、別人太過分？塔瓦布說，更常見的原因是你從來沒把話講清楚，卻默默期待別人自己發現你的底線在哪。

30 秒帶走

  • 界線是讓你在關係裡感到安全自在的期待與需要；倦怠與怨氣是缺界線的警訊。
  • 設界線只有兩步：清楚說出口，然後用行動守住；說了不做等於沒設。
  • 罪惡感是正常的副作用，不代表你做錯；別人怎麼反應也不是你的責任。

作者與時代背景

內卓・格洛弗・塔瓦布是美國的執業心理治療師，在北卡羅萊納州經營自己的諮商所，做了十多年的關係治療。她會寫這本書，是因為在診療室裡一再看到同一件事：來談的人說的是焦慮、憂鬱、婚姻不順、跟媽媽處不來、工作快把自己壓垮——往下問，問題的根幾乎都通到同一個地方：他們沒有界線，或者不知道怎麼設。

她自己也是過來人。書裡她提到自己成長於一個界線模糊的家庭，年輕時很難對家人說不，借錢出去、收拾別人的爛攤子，直到讀研究所接觸心理治療，才開始一點一點學會。

她後來在 Instagram 上用極短的文字分享界線的觀念和可以直接照念的句子，累積了大量追蹤者。2021 年這本書出版時，正值疫情期間——居家辦公讓工作和生活糊成一片，家人整天關在一起，許多人第一次清楚感覺到自己需要界線卻說不出口。這本書因此迅速登上暢銷榜。它的特色是幾乎沒有理論包袱，通篇是分類、判斷標準和範例句。

這本書回答什麼問題

「我知道應該拒絕，但我就是說不出口；好不容易說了，又內疚得要命。怎麼辦？」

市面上講界線的書不少，多數花大篇幅說明界線為什麼重要。塔瓦布預設你已經知道了，她處理的是卡住人的那幾個實際問題：我怎麼知道自己缺界線？界線有哪些種類？具體要怎麼講？講了對方不理、翻臉、裝可憐怎麼辦？內疚怎麼辦？

她對界線的定義很樸素：界線是幫助你在關係中感到安全與自在的期待和需要。它不是懲罰別人的手段，也不是把人推開的牆，而是告訴別人「怎麼跟我相處」的說明書。她反覆強調一個前提：別人不會讀心。你不說，就不能怪對方踩線。

核心概念深講

一、你需要界線的訊號，以及三種界線狀態

塔瓦布列出一串「你可能缺界線」的訊號：長期覺得不堪負荷、對請你幫忙的人心生怨恨、開始躲某些人的電話、常幻想丟下一切消失、沒有屬於自己的時間、老是在抱怨為別人做了多少卻沒有回報。她特別點名三種情緒當警示燈——倦怠、怨恨、逃避。尤其是怨恨：當你對某人越來越不爽，多半是因為你答應了一件其實不想答應的事。

她把人的界線狀態分成三種：

  • 鬆散的界線：過度分享、難以說不、討好、過度涉入別人的問題、把別人的情緒當成自己的責任、害怕被拒絕所以什麼都接受。
  • 僵硬的界線：為了保護自己而築牆——不向人求助、不讓人靠近、規則沒有例外、一有摩擦就切斷關係。看似很有原則，其實是另一種不健康，因為它把親密也一併擋在外面。
  • 健康的界線：清楚自己的價值觀、聽自己的意見、適度地分享、可以自在地說不，也能平靜地接受別人對你說不。

同一個人在不同關係裡可能是不同狀態：對同事僵硬，對家人鬆散，這很常見。

實用價值：很多人以為界線只有「太少」一種毛病。塔瓦布把「僵硬」也列為問題，提醒那些動不動就封鎖、斷聯的人——那未必是有界線，可能只是用逃避取代了溝通。

二、六種界線

界線不只是「拒絕別人的要求」。她分出六個領域，幫你定位自己到底是哪一塊被踩：

  1. 身體界線：個人空間與肢體接觸。不想被擁抱、不喜歡別人站太近、不願意別人評論你的身材，都屬於這裡。
  2. 性界線：未經同意的碰觸、性暗示、黃色玩笑。她特別強調，孩童不可能對性表示同意，這條線被侵犯是絕對的。
  3. 智識界線：你有權擁有自己的想法與意見，不被嘲笑或貶低。它也包含「什麼話題適合對誰說」——對年幼的孩子傾訴大人的婚姻問題，就是越過了這條線。
  4. 情緒界線：你的感受不被否定（「這有什麼好難過的」）、別人不把過量的情緒倒給你、你的私事不被拿去到處說。
  5. 物質界線：你的錢與東西。借了不還、把你的東西弄壞、把你的慷慨當作理所當然。
  6. 時間界線：她說這是人們最常出問題的一項。過度承諾、無償加班、隨叫隨到、明明沒空卻答應，都是時間界線失守。

每一種她都附上「越線的例子」和「可以怎麼說」。例如時間界線：「我星期二之後才有空幫忙」「我沒辦法待到那麼晚」；情緒界線：「我跟你說這些的時候，需要的是你聽，不是建議」。

常見誤用：把這份清單當成控訴別人的罪狀表。塔瓦布的用法是倒過來的：先用它找出你自己還沒說清楚的地方。

三、兩個步驟：說出口，然後做到

塔瓦布把設界線簡化成兩步：溝通與行動。

第一步的關鍵是用「堅定自信」的方式說。她列出四種行不通的溝通方式：被動（不說，默默忍，希望對方自己懂）、攻擊（用罵的、羞辱的、威脅的）、被動攻擊（嘴上說沒事，卻用擺臉色、拖延、酸言酸語表達）、操控（用罪惡感或裝可憐讓對方照做）。堅定自信則是直接、清楚、不帶攻擊地說出你的需要。她給了一個簡單的句型：「我想要⋯⋯」「我需要⋯⋯」「我希望⋯⋯」，後面接具體的事。

她對「怎麼說」有幾個反直覺的提醒：

  • 不要過度解釋。解釋越多，越像在請求批准，也給對方越多可以反駁的空隙。
  • 不必道歉。為界線道歉，等於暗示這個界線可以商量。
  • 盡量當下就說。拖越久越難開口，也越容易累積成爆炸。
  • 可以用傳訊息的。她很務實：當面說當然最好，但如果寫訊息是你唯一做得到的方式，那也比不說強。

第二步才是多數人失敗的地方：說了，但沒有守。你說「晚上九點後我不回工作訊息」，結果十點照回——對方學到的是你的話不算數。界線要靠你自己的行動來維持，而不是指望對方自律。她也區分了「後果」和「威脅」：健康的後果是你事先說明、自己做得到、也真的會執行的事（「如果你繼續大聲吼，我會掛電話」），不是用來嚇人的空話。

限制：書裡的範例句短而直接，很美式。換到比較重視含蓄與輩分的文化裡，句子的包裝得調整，但「說清楚」和「說到做到」這兩個核心不必變。

四、別人的反應與你的罪惡感

設了界線之後會發生什麼？塔瓦布很誠實：不會太舒服。她列出人們面對別人設界線時的常見反應——反彈（「你變了」「你以前不是這樣」）、試探底線（故意再犯一次看你是不是認真的）、無視（當作你沒說過）、講理與質疑（「為什麼不行？這又沒什麼」）、防衛（把焦點轉成你在指責他）、搞消失或冷戰，當然也有接受——她說，其實接受才是最常見的反應，只是我們在腦中預演的總是最壞的那幾種。

她的提醒是：對方的反應屬於對方。一個人對你的界線大發雷霆，往往正好說明這條界線有多必要——從你沒有界線這件事上得到最多好處的人，通常反對得最大聲。

至於罪惡感，她的說法大概是全書最讓讀者鬆一口氣的一句：沒有「零罪惡感」的設界線方法。尤其是從小被教導「懂事就是配合別人」的人，第一次說不一定會覺得自己很壞。她的建議不是消除罪惡感，而是帶著它照樣去做——把它當成一種感覺，不當成一個判決。感覺會過去，而界線留下來的平靜會累積。

書中也談到比較嚴重的越界型態，她用「小越界」與「大越界」來分：前者是日常的小摩擦（愛問隱私的親戚、過度分享的同事、讓你內疚的說法），後者則已經侵蝕了關係的結構，例如彼此糾纏不清、分不出誰的事是誰的事的「共融」，以及靠著替對方收爛攤子來維繫的「共依存」。後半本書就按場景一一處理：原生家庭、伴侶、朋友、職場、社群媒體與科技。最後一塊也很重要——對自己的界線：花錢、作息、滑手機、對自己說過的話算不算數。

整本書的邏輯骨架

塔瓦布的鏈條很短：倦怠、怨恨、逃避是訊號 → 訊號指向某個沒被說出口的需要 → 用六種界線定位是哪一塊 → 用堅定自信的方式說出來 → 用自己的行動守住 → 預期會有不舒服（對方的反應、自己的罪惡感）並且撐過去 → 重複。前半本是這條鏈的原理，後半本是把同一條鏈套進家庭、愛情、友誼、工作、科技各個場景。它不是要你變得強硬，是要你變得清楚。

實作指南：明天就能開始

職場版：

  1. 找出這個月最讓你有怨氣的一件工作，問：我當初答應的時候，其實想說什麼？
  2. 準備一句不帶解釋的回覆並實際用一次：「我目前手上的事排到週四，這件我接不了。」
  3. 設一條時間界線並用行動守住：下班後關掉工作通知，隔天早上再回。
  4. 有人慣性把事丟給你時，把問題還回去：「這部分你打算怎麼處理？」
  5. 被追問理由時，重複原句就好，不加新的解釋。

生活版：

  1. 用六種界線掃一遍最讓你疲憊的那段關係，找出被踩得最兇的是哪一種。
  2. 寫下一句「我需要⋯⋯」，短到一口氣能講完，先念給自己聽。
  3. 挑一個風險低的對象先練（朋友、手足），再處理最難的那個人。
  4. 事先想好對方可能的三種反應，以及你要重複的那一句話。
  5. 罪惡感來的時候告訴自己：這是預料中的感覺，不是我做錯的證據。
  6. 給自己設一條界線：例如睡前一小時不看手機，並且真的做到。

常見誤讀

  1. 「設界線就是學會拒絕、把人推開」——塔瓦布把「僵硬的界線」也列為問題。界線的目的是讓關係能繼續，而且繼續得不帶怨氣；動輒斷聯往往是不敢溝通的另一種表現。
  2. 「我設了界線，對方就應該改變」——界線管的是你自己會怎麼做，不是對方必須怎麼做。對方可以不配合，而你決定接下來你要怎麼辦。把界線當成控制別人的工具，就走樣成最後通牒了。
  3. 「說一次就夠了」——她明講多數界線需要重複說、重複守。對方試探是正常過程，不代表失敗。

延伸對照

  • 《界線》（亨利・克勞德、約翰・湯森德）：書庫八月讀過的經典，談的是界線的觀念與責任歸屬，帶有信仰背景；塔瓦布這本更像操作手冊，句子可以直接拿去用。
  • 《情緒勒索》（蘇珊・佛沃）：塔瓦布列的「反彈、試探、讓你內疚」，在佛沃那裡有更深入的心理剖析；一本幫你看懂對方的手法，一本幫你準備好要說的話。
  • 《假性孤兒》（琳賽・吉普森）：月初讀過。對原生家庭設界線最難，因為還抱著對方會改變的期待；先放下期待，塔瓦布的句子才說得出口。

金句

  1. 「界線是幫助你在關係中感到安全與自在的期待和需要。」（Boundaries are expectations and needs that help you feel safe and comfortable in your relationships.）
  2. 「別人不知道你要什麼，把它說清楚是你的責任。清楚，才能挽救關係。」（大意）
  3. 「沒有不帶罪惡感的設界線方法。」（大意）

討論題（回訊息聊聊）

  1. 倦怠、怨恨、逃避——你最近最明顯的是哪一個？它指向哪一段關係、哪一種界線（身體、性、智識、情緒、物質、時間）？
  2. 寫下一句你一直想對某個人說、卻還沒說的「我需要⋯⋯」。是什麼讓你到現在還沒開口：怕對方的反應，還是怕自己的罪惡感？
